Description

Bit-level cotraversals and grates for Word types.

Each Word type is isomorphic to a function from a finite index type: Word8 ≅ I8 -> Bool. Since (->) I8 is Distributive, cotraversed gives cotraversals for free.

-- flip all bits
over bits8 not 0xFF  ==  0

-- identity
over bits8 id 42  ==  42

-- indexed: flip only even-positioned bits
cxover ibits8 (\i b -> if even (fromEnum i) then not b else b) 0xFF

Cotraversal over the 8 bits of a Word8.

~44 ns/bit. Prefer ibits8 (~7 ns/bit) when the index is available. See the Benchmarks section of the README for details.

bits8 = iso toBits8 fromBits8 . cotraversed

Byte-level grates

grate8 :: Colens Word8 Word8 (I8 -> Bool) (I8 -> Bool) Source #

Grate viewing a Word8 through its bit representation.

~21 ns/bit. Faster than bits8 (~44 ns/bit), slower than ibits8 (~7 ns/bit). Use when you need Closed but not the coindex. See README.

grate8 = grate (\f -> fromBits8 (f . toBits8))
