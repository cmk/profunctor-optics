profunctor-optics-containers

Extended optics for containers types that require additional dependencies (nonempty-containers, scheme-extensions). Includes nonempty Map optics, pattern functors for recursion schemes, and structural operations (depth, sizes, rebalanced).

The standard container optics (Map, IntMap, Set, IntSet, Seq, Tree, List) live in the core profunctor-optics package.

See the README for more information.
