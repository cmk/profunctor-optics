Description

Bit-level cotraversals and grates for Word types.

Each Word type is isomorphic to a function from a finite index type: Word8 ≅ I8 -> Bool. Since (->) I8 is Distributive, cotraversed gives cotraversals for free.

-- flip all bits
over bits8 not 0xFF  ==  0

-- identity
over bits8 id 42  ==  42
