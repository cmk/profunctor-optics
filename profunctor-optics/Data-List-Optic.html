Sort a list with a stable sort, grouping equal elements.

The core primitive: sort by comparator, then aggregate runs of equal elements with the grouping function.

groupSortBy compare (\x xs -> x : xs) = sortBy compare . group

groupSort :: Ord a => (a -> [a] -> b) -> [a] -> [b] Source #

Sort a list, grouping equal elements.

groupSort (\x xs -> x : xs) [3,1,2,1,3] = [[1,1],[2],[3,3]]
