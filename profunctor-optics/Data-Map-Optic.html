Description

Left and right carriers are characterized by their representation functors (Rep and Corep). Iso sits at the top where both are trivial (Identity). Adjoint sits at the bottom where they form a full adjunction (Corep p ⊣ Rep p). A left-indexed (Ix) optic threads an index through the left adjoint functor (,) k, while a right-indexed (Cx) optic threads a coindex through the right adjoint functor (->) k.

Profunctor optics for strict Map.

For lazy variants, import Data.Map.Lazy.Optic.

For structural optics (depth, sizes, rebalanced) that require pattern functors, see Data.Map.Fold.Optic in profunctor-optics-containers.

data Map k a #

A Map from keys k to values a.

The Semigroup operation for Map is union, which prefers values from the left operand. If m1 maps a key k to a value a1, and m2 maps the same key to a different value a2, then their union m1 <> m2 maps k to a1.

Costar Optics

Colens

zippedIfKey :: Ord k => Set k -> Colens (Map k a) (Map k b) (k -> Maybe a) (k -> Maybe b) Source #

Colens viewing a Map as a partial function from keys.

Self-keyed: the key set comes from the focal map (via copure). The focus is k -> Maybe a — Nothing for keys absent from a given map. No external key set or default needed.

zipsWith zippedIf f m1 m2

zips m1 and m2 over m2's keys (since copure (m1,m2) = m2 for (,)). Missing keys in m1 appear as Nothing.

| Colens viewing a Map as a partial function from keys. The focus is k -> Maybe a — Nothing for absent keys. Requires a fixed key set (Colens has no copure).
