Description

Profunctor optics for Map.

Unprimed variants are lazy. Primed (') variants are strict.

For structural optics (depth, sizes, rebalanced) that require pattern functors, see Data.Map.Fold.Optic in profunctor-optics-containers.

Dual Optics

cxmapped' :: Cxview k (Map k a -> Map k b) (a -> b) Source #

O(n). Coindexed review for Map: reconstruct a map with key-dependent logic.

Built via cxfrom mapWithKey. The coindex k is the map key — available on the reconstruction side. Dual of ixmapped.

Compose with (#) for multi-level coindexed operations:

cxfoldMapOf (cxmapped # cxmapped) f r nestedMap
